# מי מושך את התוכנית

משחק כיתה לשיעור 5 בקורס תחיקת הבנייה, `vaada-artzit` - הוועדה הארצית לתכנון ובנייה, הרכב, ועדות משנה, תמ"א ותת"ל.

משיכת חבל בין ארבע קבוצות, מוקצבת בזמן. המסך מחולק לארבעה ריבועים, ובמרכזם טבעת שארבעה חבלים קשורים אליה. כל תשובה נכונה ומהירה של סטודנט מושכת את הטבעת לכיוון השטח של הקבוצה שלו. הקבוצה שהטבעת נמצאת בשטחה כשנגמר הזמן מנצחת.

## ארבע הקבוצות

הקבוצות אינן שרירותיות. אלה ארבעת האינטרסים שמושכים את מערכת התכנון הארצית לכיוונים מנוגדים:

| קבוצה | מי זה | מיקום בלוח |
|---|---|---|
| הממשלה | שליש מחברי המועצה הארצית | צפון מזרח |
| הרשויות המקומיות | שליש מחברי המועצה הארצית | צפון מערב |
| הירוקים | הולקחש"פ, הולחו"ף, ונציג ארגון הגג לאיכות הסביבה בות"ל | דרום מערב |
| התשתיות | הות"ל והתת"ל | דרום מזרח |

השיוך אקראי ונעשה בטרנזקציה על מונה משותף, ולא בהגרלה בטלפון עצמו, כדי שכמה מכשירים שנכנסים באותו רגע לא ייפלו כולם לאותה קבוצה. התוצאה היא קבוצות שוות בגודלן עד הפרש של אחד.

## הכללים

- שעון אחד לכל הכיתה, שש עד עשר דקות לבחירת המרצה.
- כל סטודנט רץ על בנק השאלות בקצב שלו, בסדר מעורבב אחרת לכל אחד. אין סבבים משותפים.
- תשובה נכונה: 60 נקודות בסיס ועוד בונוס מהירות של עד 140, בדעיכה מעריכית. מיידית כ-200, אחרי שלוש שניות כ-140, אחרי עשר כ-83.
- תשובה שגויה: אפס נקודות ונעילה של שלוש שניות, שבמהלכן מוצגת התשובה הנכונה. אין משיכה לאחור, כדי שסטודנט אחד שמנחש לא יפיל את הקבוצה ושהחלשים לא יפסיקו לענות מפחד.

## הפיזיקה

מיקום הטבעת הוא מרכז המסה של ארבע המשיכות:

```
טבעת = מרכז + ( Σ משיכה_קבוצה × כיוון_הפינה ) / ( Σ משיכה + חיכוך ) × רדיוס_מרבי
```

שני דברים נובעים מזה מעצמם, בלי חוקים מלאכותיים: קבוצות שיושבות בפינות נגדיות מבטלות זו את זו, ושוויון בין ארבע הקבוצות משאיר את הטבעת במרכז. החיכוך (220) מונע מהתשובה הנכונה הראשונה במשחק להטיס את הטבעת לפינה.

**המשיכה היא ממוצע לחבר ולא סכום.** בלי זה, קבוצה בת חמישה מנצחת קבוצה בת ארבעה בזכות המניין ולא בזכות הידע. המשמעות הנוספת היא שסטודנט חזק אחד לא סוחב קבוצה שלמה לבד.

אם בסוף הזמן הטבעת נמצאת בתוך רדיוס של שבעה אחוזים מהמרכז, אף קבוצה לא הכריעה וההכרעה נופלת לפי המשיכה הממוצעת. המסך אומר את זה במפורש.

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מסך המרצה: לובי עם QR, הזירה, ומסך הסיום |
| `play.html` | הטלפון של הסטודנט, כולל תצוגת חבל מוקטנת |
| `solo.html` | תרגול אישי בלי Firebase, ארבע דקות מול שלוש קבוצות שמושכות בקצב קבוע |
| `tools/questions.json` | **מקור התוכן.** האפשרות הראשונה בכל שאלה היא הנכונה |
| `tools/build-data.mjs` | מייצר את `js/gameData.js` ומערבב את התשובות בזרע קבוע |
| `js/gameData.js` | נוצר אוטומטית. לא לערוך ידנית |

לשינוי תוכן: לערוך את `tools/questions.json` ולהריץ `node tools/build-data.mjs`.

## התוכן

37 שאלות. הבסיס הוא עשר שאלות ראשי התיבות שארז כתב ב-Wayground (תמ"א, תמ"מ, תב"ע, ות"ל, תת"ל, ולקחש"פ, ולחו"ף, ותמ"ל, ולנת"ע, מר"מ), כולל המסיחים המצחיקים המקוריים. עליהן נבנו 27 שאלות תוכן מתוך `content.body` של השיעור באתר: הרכב המועצה הארצית, מה היא מאשרת בעצמה ומה עובר לממשלה, הולקחש"פ והולחו"ף והתוספות שמכוננות אותן, והות"ל על הרכבה, תיקון 60, ההכרזה המשולשת וסמכות הרישוי הישירה שלה.

עשר שאלות ראשי התיבות הוסרו ממשחק הפירמידה של שיעור 6, שם הן ישבו קודם, והוחלפו שם בשאלות תוכן מאותם אזורים בהר.

## Firebase

פרויקט נפרד: `erez-chevel-game`, Realtime Database ב-europe-west1.

```
game/        { state: lobby | running | finished, startedAt, durationSec, endsAt }
players/{id} { name, team, avatar, score, correct, wrong, lastAt, lastOk, lastPts, lastQ }
teamCounts   { c: [n,n,n,n], last }
```

כל שחקן כותב רק את הצומת של עצמו. מסך המרצה הוא היחיד שכותב ל-`game`.

## הדמויות

שמונה איורי AI ב-`images/`, נוצרו ב-Gemini לפי `tools/avatar-prompts.md`. הפרומפטים נשמרים כי הם המפתח להוספת דמות תשיעית באותו סגנון.

המקורות הגיעו 2048 על 2048 עם מסגור רחב, ובקוטר 44 פיקסלים הפנים היו יוצאות זעירות. `tools/crop-avatars.py` חותך כל אחת סביב הראש והכתפיים ומקטין ל-256. ערכי החיתוך שונים בין הדמויות: כובע הקש של החקלאי דורש חיתוך רחב יותר בגלל השוליים, וראש העיר הגיע ממוסגר צפוף ולכן כמעט לא נחתך.

שמות הקבצים חייבים להישאר `avatar1` עד `avatar8`. אחרי החלפת קובץ יש להריץ `node tools/build-data.mjs`.
